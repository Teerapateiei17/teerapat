## Setup

This is a PHP/MySQL project. To run locally:

1. Install a web server (e.g., XAMPP, MAMP, or LAMP)
2. Import the database from `f/8032db.sql`
3. Configure database connection in `connectdb.php`
4. Start the Apache server and MySQL
5. Open the project in a browser
